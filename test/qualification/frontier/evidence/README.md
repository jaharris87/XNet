# Retained Frontier evidence

Each dated directory contains only the compact, validated, path-neutral
manifest and its review note for one accepted issue #46 qualification. Raw
executables, object/module files, source archives, runtime histories, absolute
machine paths, and allocation/account data remain in the external Frontier
artifact directory.

No run is retained here until its source commit, environment, builds, direct
GPU residual, partial-batch semantics, `heat_sn160` comparison, numerical
policy, and complete artifact inventory have been reviewed.
